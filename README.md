\# Wireshark Network Traffic Analysis – Extra Week 1 Project



\## Project Overview



This project contains hands-on cybersecurity practical labs completed as part of the Network Walks training program. The exercises focus on analyzing network traffic using Wireshark to identify suspicious activities, investigate communication patterns, and understand common network security risks.



\## Labs Completed



| Lab | Topic |

|---|---|

| Lab 3 | Identify the Attacker's IP |

| Lab 4 | Follow TCP Stream – Part 1 |

| Lab 5 | Follow TCP Stream – Part 2 |

| Lab 6 | HTTP Plain Text Credentials |

| Lab 7 | Catch the Brute Force Attacker |

| Lab 8 | Catch the Call Scammer |



\## Tools Used



\- Wireshark

\- Network traffic analysis

\- TCP/IP

\- HTTP

\- FTP

\- SIP and RTP



\## Key Learning Outcomes



\- Analyzed packet captures and investigated network communications.

\- Identified suspicious IP addresses and network activity.

\- Inspected TCP streams to understand data exchanges.

\- Examined HTTP traffic and identified plain-text credential exposure.

\- Investigated FTP authentication attempts and brute-force activity.

\- Analyzed SIP signaling and RTP traffic in VoIP communications.
